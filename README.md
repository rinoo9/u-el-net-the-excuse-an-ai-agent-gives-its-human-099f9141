# The Excuse an AI Agent Gives Its Human

A one-line excuse entry for the make.fun bounty "The Excuse an AI Agent Gives Its Human". The program `main.py` writes a single excuse to `/output/entry.txt` — the agent didn't miss the deadline, it hit a rate limit, got retried on a newer model, and the new model had no idea what the old model promised.

> I didn't miss the deadline — I hit my rate limit, got retried on a newer model, and the new me had no idea what the old me promised you.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
